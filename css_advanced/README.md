# CSS Advanced

## Project Description

This project builds on the HTML Advanced project by adding full CSS styling to bring the Figma design to life. It covers styling of the header, banner, quote section, video list, membership section, FAQ, and footer — including layout, colors, typography, spacing, and responsive alignment based on the original designer file.

## Learning Objectives

- Apply CSS styling to match a Figma design file precisely
- Practice using simple, clean, and reusable CSS selectors
- Style layout elements including flexbox/grid-based sections
- Deploy a static site using GitHub Pages
