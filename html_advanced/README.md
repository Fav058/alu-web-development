# HTML Advanced

## Project Description

This project is the first step in building a webpage from a Figma design file, focusing purely on HTML semantic structure — no CSS or styling is applied at this stage. The goal is to translate a designer's wireframe into clean, well-structured, semantic HTML using appropriate tags such as `header`, `main`, `section`, `footer`, headings, and text elements.

The page is broken down into distinct sections: a header with navigation, a banner, a quote block, a video list, a membership section, an FAQ, and a footer — each mirroring the layout provided in the Figma design.
